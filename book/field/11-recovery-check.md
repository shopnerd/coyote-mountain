# Field card 11 · Recovery check

Measure a recovery area the same way each time, beside an untreated area, so you can tell what the work did.

**People:** 2  
**Tool:** coyotemountainfarm.com/topo.html · Study · recovery and Site · field notes  

## Before the first check

1. Study · recovery: **draw a recovery area**, and a similar patch to leave alone (**finish: an untreated area to compare**).
2. Add goals: bare ground, water soaking in, native plant cover.
3. Mark two permanent tape lines in each area with pins at both ends, and a photo point (card 03).

## Bare ground, by line-point intercept

1. Stretch a 50 m tape between the pins.
2. Every 50 cm, drop a thin rod straight down beside the tape. Record what it touches first on the ground: bare soil, plant, litter or rock.
3. That is 100 points. % bare ground = the number of bare-soil points.
4. Do both lines. Use the average.

## Native cover

Along the same tape, count the points where the rod touches a native plant first. That is % native cover.

## Infiltration

Three tests in the area (card 04).

## Record it

1. Site · field notes inside the area: **kind** vegetation with the % cover, **kind** soil infiltration test with the rate.
2. Study · recovery: pick the area, **use field notes inside as measurements**, or add a value by hand to each goal.
3. Take the photo point photo.
4. Do the same in the untreated area.

## Good to know

- Same tape lines, same season, same people if you can. Consistency is what makes the change real.
- The untreated area is the honest measure. If both improved, rain did some of it.

## Done when

Both areas measured, goals updated, photos taken.
