# Field card 03 · Field notes and photo points

Record what you find on the land so it can be compared later: a note, a photo, an erosion spot, a spring, a tree to keep.

**People:** 1  
**Tool:** coyotemountainfarm.com/topo.html · Site · field notes  

## Bring

- phone with the project open
- a few permanent markers for photo points: a rebar pin, a painted rock, a post

## A note

1. **Kind:** note, photo, erosion, vegetation and so on.
2. **Measured by:** phone, eye or tape, rtk survey, sensor or lab test. This sets how accurate the note is, and it stays with the note.
3. **Value** if there is one, **date**, and **what you saw** in a few words.
4. **Add a photo** if it helps.
5. **Note it where I stand** uses the phone position. **Note it on the plan** lets you tap the spot instead.

## A photo point

A photo point is the same view taken again and again, so change shows.

1. Set a permanent marker. Stand on it.
2. Take the photo facing the same way each time: pick a landmark on the horizon and put it in the same place in the frame.
3. Add a note of kind **photo**, with the photo, and write the landmark in *what you saw* (for example: *facing the big oak, north*).
4. Next time, stand on the same marker, face the same landmark, same season if you can.

## Good to know

- Write what you saw, not what you think caused it. *Gully 40 cm deeper at the road culvert* is a note. *The culvert is causing it* is a guess, and belongs in a separate note.
- Photos are shrunk to keep the project file small. Keep the originals on the phone.

## Done when

- the note shows in the list with its date and marker on the plan
- the project is saved

## After

**Save notes · csv** gives a spreadsheet of every note with place, value, method and accuracy.
