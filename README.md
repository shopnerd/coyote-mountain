# Coyote Mountain Studio

Will's creative sandbox for coyotemountainfarm.com.

- index.html: landing page for the two tools
- sketch.html: geometric + kinetic sketch tools (unlinked while it is worked on)
- topo.html: landscape grading tool (contours, hachures, 3D, sections, STL, laser-cut cardboard stack, real terrain, drone survey import)
- flight.html: drone photogrammetry flight planner on the same terrain
- flight.html: drone flight planner for photogrammetry (survey area on real terrain, terrain-following lawnmower lines, GSD/overlap/battery math, KML · GeoJSON · Litchi CSV · DJI WPML exports)

Single files, no build, no libraries.
